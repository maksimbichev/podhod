# Подход

Личный дневник тренировок. Офлайн-PWA: работает без интернета, ставится на экран «Домой».

- Данные хранятся только на устройстве (IndexedDB + запасная копия), никуда не отправляются.
- Ни одного внешнего запроса: без шрифтов, CDN и аналитики.
- Бэкап и загрузка через файл JSON.

В этом репозитории только код, личных данных здесь нет.
